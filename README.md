# Portfolio Website

HTML, CSS, JavaScript로 제작한 개인 포트폴리오 웹사이트입니다.

GitHub API를 사용해 GitHub public repository 목록을 불러오고, 프로젝트 카드 형태로 화면에 표시합니다.

## 배포 주소

https://book732.github.io/portfolio_1/

## 주요 기능

- 반응형 웹 디자인
- 모바일 메뉴 토글
- GitHub API를 이용한 저장소 목록 표시
- 프로젝트 카드 UI
- 연락처 폼 입력 및 제출 알림
- GitHub Pages 배포

## 사용 기술

- HTML
- CSS
- JavaScript
- GitHub API
- GitHub Pages
